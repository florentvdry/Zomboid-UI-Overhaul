# Changelog

## 1.0.0 — 2026-10-21

First public release, based on the development builds previously numbered 2.1.x.
The public version starts at 1.0.0; the internal mod ID stays `N26_UIOverhaul`.

- One tactical screen with Character, Inventory, Health, Crafting and Map tabs.
- 3D equipment view, worn/held slots, health summary and nearby loot.
- Character identity, traits, grouped skills, live levels, XP and reading bonuses.
- Recipe search, categories, favourites, requirements and quantity selection.
- Construction mode uses the native placement cursor.
- Native map exploration, zoom, markers and options.
- French and English labels; native mod options for accent, opacity and modules.
- Physical skills follow Build 42.21's `PhysicalCategory`.
- XP and reading labels display without leaked formatting tokens.
- The world dimmer excludes docked windows; missing care supplies remain readable.

Validation: author reported the five tabs working in game before the last display
fixes. The display fixes passed 26 focused automated tests. Final in-game review
and replacement screenshots are still pending; no public upload has been made.
