# Changelog

## 1.0.0 — 2026-10-21

Initial release for Project Zomboid Build 42.21+.

- One tactical screen with Character, Inventory, Health, Crafting and Map tabs.
- 3D equipment view, worn/held slots, health summary and nearby loot.
- Character identity, traits, grouped skills, live levels, XP and reading bonuses.
- Recipe search, categories, favourites, requirements and quantity selection.
- Construction mode uses the native placement cursor.
- Native map exploration, zoom, markers and options.
- French and English labels; native mod options for accent, opacity and modules.
