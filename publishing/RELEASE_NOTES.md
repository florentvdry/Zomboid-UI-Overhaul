# Zomboid UI Overhaul — v1.0.0

Initial public version for Project Zomboid Build 42.21+.

Press **Tab** to open a single tactical screen for Character, Inventory, Health,
Crafting and Map. Includes a 3D equipment view, grouped skills and XP, nearby
medical supplies, recipe search and native map controls. English and French.

Enable the mod in **Mods**, then restart the game. Configure it in **Options > Mods**.
Mouse and keyboard only; controller players and the tutorial keep the native UI.
The screen preserves native transfers, treatment and crafting interactions.

- `N26_UIOverhaul-source-1.0.0.zip`: source, documentation and development tools.

**Mod ID:** `N26_UIOverhaul` · **Minimum game build:** `42.21`.

Potential conflicts: mods replacing the same inventory, health, skills, crafting
or map UI. Multiplayer compatibility has not been broadly verified.
