# Zomboid UI Overhaul — V1.0.0

Requires Project Zomboid Build 42.21 or later. Mod ID: `N26_UIOverhaul`.

[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3824243701)

## English

Extract the `N26_UIOverhaul` folder into your user `Zomboid/mods` directory.
Check that `N26_UIOverhaul/42/mod.info` and `N26_UIOverhaul/common` exist.
Enable the mod in Mods, then restart the game.

Tab opens/closes the tactical screen. With default bindings, H opens Health,
L Character, B Crafting and M Map. Escape closes it. Settings are in
Options > Mods > Zomboid UI Overhaul. Mouse and keyboard only; controller
players and the tutorial use the native interface.

## Français

Décompressez le dossier `N26_UIOverhaul` dans votre dossier utilisateur
`Zomboid/mods`. Vérifiez la présence de `N26_UIOverhaul/42/mod.info` et de
`N26_UIOverhaul/common`. Activez le mod dans Mods puis redémarrez le jeu.

Tab ouvre/ferme l’écran. Avec les touches par défaut : H pour Santé, L pour
Personnage, B pour Fabrication et M pour Carte. Échap ferme l’écran.
Réglages : Options > Mods > Zomboid UI Overhaul. Clavier et souris uniquement.

## Compatibility / Compatibilité

Build 41 is unsupported. Other mods replacing the same UI windows may conflict.
Close the screen before quitting to avoid saving docked inventory sizes.
Broad multiplayer compatibility has not been verified.

Build 41 non prise en charge. Les autres mods remplaçant les mêmes fenêtres
peuvent entrer en conflit. Fermez l’écran avant de quitter le jeu.
La compatibilité multijoueur n’a pas fait l’objet de tests étendus.
