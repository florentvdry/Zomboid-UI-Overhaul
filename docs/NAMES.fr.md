# Nom public et identité

Nom choisi par l’auteur le 21 octobre 2026 : **Zomboid UI Overhaul**.
Signature : **by N26**.

Le nom annonce la refonte de l’interface de Project Zomboid et couvre les cinq
onglets sans réduire le mod à l’inventaire ou à une orientation tactique.

- Nom affiché du mod, des options et du Workshop : `Zomboid UI Overhaul`.
- Nom proposé pour le dépôt GitHub : `zomboid-ui-overhaul`.
- Version publique : `1.0.0`.
- Identifiant technique conservé : `N26_UIOverhaul`.
- Espace de noms Lua et identifiant des options conservés : `N26` / `N26_UIOverhaul`.

Les dossiers et archives gardent l’identifiant technique pour préserver les
réglages et faciliter les mises à jour. Le générateur des visuels lit le nom
et la version dans `42/mod.info` ; relancer `npm run branding` puis
`npm run release` après toute évolution de ces métadonnées.
